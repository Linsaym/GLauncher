# Работа с Codex

Для задач, затрагивающих оба пакета, открывайте GLauncher из корня. Для задач одного пакета можно открыть сессию Codex с рабочим каталогом `apps/client` или `apps/update-server`. Codex собирает `AGENTS.md` от корня Git до рабочего каталога. В корневой сессии инструкции пакета доступны по ссылкам из корневого `AGENTS.md`. [Документация Codex о проектных инструкциях](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

## Постановка задачи

```text
Цель — какое поведение должно появиться или измениться.
Область — пакет и известная точка входа.
Критерии — наблюдаемый результат и существенные пограничные случаи.
Проверка — команда из AGENTS.md и нужный пример входных данных.
```

Если задача продолжается в новой сессии, передайте сделанное, затронутые файлы, результаты проверок и ближайший открытый вопрос. Долговременные сведения держите рядом с кодом. Правила работы принадлежат `AGENTS.md`, описание архитектуры и границ — `docs/architecture.md`, запуск окружения — `README.md`.
