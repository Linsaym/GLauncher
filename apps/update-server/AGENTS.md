# Сервер обновлений

- `src/index.ts` запускает HTTP-сервер, `src/server.ts` создаёт его для запуска и тестов.
- Сохраняй возможность запускать сервер независимо от Electron и React. При появлении HTTP-контракта согласуй схему между пакетами и проверяй её на синтетических данных.
- Из корня запускай `npm.cmd test --workspace @glauncher/update-server`. Тест использует локальный адрес и порт, назначенный ОС.
