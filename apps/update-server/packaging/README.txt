GLauncher — сервер обновлений для Windows x64

1. Распакуйте архив целиком.
2. Запустите start-server.bat. Сервер создаст папку mods рядом с BAT.
3. Добавьте в mods разрешённые к распространению клиентские JAR.
4. Для остановки нажмите Ctrl+C в окне сервера.

По умолчанию сервер доступен на 127.0.0.1:3000.
Игрокам укажите IP и порты сервера в настройках GLauncher.
Чтобы слушать адрес локальной сети или VPN, откройте PowerShell в папке сервера:

  $env:GLAUNCHER_HOST = "192.168.1.10"
  $env:GLAUNCHER_PORT = "3000"
  .\start-server.bat

Укажите фактический адрес вашего ПК и разрешите доступ с адресов игроков
в брандмауэре. Папку модов можно изменить через GLAUNCHER_MODS_DIR.
Используйте сервер обновлений в доверенной сети или через VPN.
Node.js и его лицензия находятся в папке runtime.
