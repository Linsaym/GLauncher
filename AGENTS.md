# Работа с GLauncher

Клиент рассчитан на Windows. В репозитории два npm workspace: Electron-клиент и самостоятельный HTTP-сервер обновлений.

- Перед правками проверь `git status --short` и сохрани пользовательские изменения.
- Для клиента прочитай [инструкции клиента](apps/client/AGENTS.md), для сервера — [инструкции сервера](apps/update-server/AGENTS.md). Изменения IPC, HTTP или границ пакетов отражай в [архитектуре](docs/architecture.md).
- Держи установку игры, сетевые запросы и запуск процессов в Electron main. Храни игровые данные в каталоге GLauncher под `%AppData%`.
- Обновляй корневой `package-lock.json` вместе с зависимостями. Команды запускай из корня через `npm.cmd`.
- После чистого `npm.cmd ci` выполни `npm.cmd run install:electron`. Перед сдачей выполни `npm.cmd run check`.
- Тестируй на синтетических файлах во временных каталогах. Для HTTP используй loopback и порт, назначенный ОС. Не добавляй адрес приватного сервера и секреты в репозиторий.
- В отчёте укажи изменённое поведение, результаты проверок и что осталось непроверенным.
